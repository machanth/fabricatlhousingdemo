# Troubleshooting

| Symptom | Action |
|---|---|
| Wrong Azure subscription/tenant | Sign in to the configured tenant and select the approved subscription; do not weaken the guard. |
| SQL token login fails | Confirm Entra database access, ODBC Driver 18 and network reachability. Never print tokens. |
| Workbook is OLE/encrypted | Wait for the user's unencrypted originals. Installing xlrd does not decrypt OOXML; do not regenerate or bypass encryption. |
| Replacement workbook columns differ | Stop and inspect the new shape; update mapping only after confirming business meaning. |
| OneLake PathNotFound on upload | Ensure Lakehouse provisioning succeeded and parent directories exist. SDK non-overwrite append does not create missing files; use a create-only conditional create. |
| Fabric creation returns 202 | Poll the canonical operations endpoint using x-ms-operation-id; regional Location hosts are not assumed to be canonical API hosts. |
| Item name already exists | Reuse only the expected type; the Lakehouse's autogenerated SQL endpoint shares its display name. Do not delete it. |
| Gen2 creates staging items | Fabric may create managed StagingLakehouseForDataflows/StagingWarehouseForDataflows on the existing capacity. These are service-managed, not new Azure capacity provisioning. |
| Dataflow refresh fails with Blocked | Set pApprovedBatch only after full preflight/landing; bind the connection and destinations before publishing. |
| Source counts match but metrics differ | Run the full-outer comparison. Check category precedence, missing-unit retention, effective-dated PropertyID join and program-specific supportive join. |
| Vacancy appears for vouchers | Preserve null inventory and use unit-based households for the grand total; never fill missing inventory with zero. |
| Native pipeline cannot authenticate | Create/bind the selected-source Organizational account connection in Fabric. Unrelated connections are not substitutes. |
| DQ notebook reports structural errors | Inspect prd.DQ_Results and source intervals/dates. Expected planted warnings are not structural errors. |
| Deployment rerun did not change notebook | The deployer preserves existing definitions. Review live edits and explicitly update through the editor/API. |
| SQL checkpoint load takes many minutes | The current runner uses native COPY INTO from OneLake. Retire any older ODBC publisher before replay; the local publisher lock rejects competing runs. |
| Report totals double | Confirm observation grain and one-to-many single-direction relationships; never join FamilyMember directly to all snapshots or combine historical landing runs. |
| RLS passes for an admin | Retest as an approved Viewer; workspace author roles do not prove RLS. |
| Fiscal year is blank | Await the agency's fiscal-calendar convention; blank is deliberate, not a silent guessed default. |
| No alert arrived | No destination has been supplied/configured. Choose one and verify delivery using a safe forced-failure test before enabling schedules. |
